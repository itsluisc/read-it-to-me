# Read it to me

Drop a carousel. Your agent reads it to you.

Same skill for Grok, Claude, and Codex. Grok uses the Grok voice. Claude and Codex use whatever voice they already have. If they can't speak, they still hand you the script, one slide at a time.

Photo carousels only. Not videos. Not yet.

## Use

Paste a public Instagram carousel link, or drop the slide images in order.

```text
Read this to me: https://www.instagram.com/p/...
```

## Install

The skill is already in the folders those agents scan. Clone this repo into a project, or copy `skills/read-it-to-me` into one of these:

| Agent | Folder |
| --- | --- |
| Grok | `.grok/skills/read-it-to-me/` |
| Claude Code | `.claude/skills/read-it-to-me/` |
| Codex | `.agents/skills/read-it-to-me/` |
| Cursor, Copilot, Gemini | `.agents/skills/read-it-to-me/` |

Then say "read this carousel to me" and paste the link.

## Later

Video, stories, and other apps can be added. They are not part of this skill.
